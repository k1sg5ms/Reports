1채널 체크 & 리셀러 서베이 — 수요 견조 지속

  • 최신 채널 논의·리셀러 서베이(n=29)에서 PANW가 복수 보안 카테고리에 걸쳐 점유율 확대 지속 — 라이브 대화 기준 가장 강한 벤더로 평가
  • 6월 서베이: 전분기 대비 소폭 하락에도 응답자 79%가 계획 상회 또는 부합 (Above Target 52% + In line 28%)
  • 강세 배경은 방화벽 refresh + 가격 인상 전 선구매(pull-forward)뿐 아니라, 대형 멀티프로덕트 커밋·계약금액 확대·Network Security/SecOps 점유율 확대로 폭넓게 확인
  • 코어 방화벽 외에는 XSIAM이 가장 명확한 성장 동력 — 그린필드 AI-SOC 구축 및 레거시 SIEM 대체 수요, Prisma SASE도 분산 사용자·워크로드·엣지 보안 수요로 견조
  • Prisma AIRS·Mythos 관련 고객 관심 확대 중이나, 단기 수익화는 Unit 42 서비스 및 파이프라인 창출에 무게
  • CyberArk 리셀러 성과 전분기 대비 개선, AI Security 매출 비중도 분기 중 상승 — 하드웨어 단독 서프라이즈(FTNT·CSCO·FFIV)는 주가 반응이 제한적이었던 만큼 FY27 코멘터리가 촉매 역할 기대

2FQ4 핵심 지표별 전망 — 전반적 상회 예상

  • RPO/cRPO: FQ4 RPO는 가이던스($20.9~21.0B) 상단 또는 소폭 상회, +~33% YoY 전망 — cRPO 성장률은 컨센서스(~28~29% YoY) 소폭 상회 예상
  • 매출: 총매출 성장률 가이던스(~32%) 상회한 ~33% YoY 전망 — Fortinet(제품매출 +21% beat)·Cisco(네트워킹 +5% beat) 호실적 이후, PANW 제품매출도 컨센서스(~18~19%) 대비 ~22~23% YoY 예상
  • NGS ARR: 가이던스($8.90~8.95B) 상단 마감, +~60% YoY — FQ3 이후 기대치가 크게 올라온 만큼 추가 상회 폭은 제한적일 전망
  • 마진: FQ4 영업이익률 ~30%까지 상승 여지 — 매출 호조·대형 플랫폼 딜의 영업 생산성 개선 효과, 하드웨어 비중 확대·부품 원가 상승이 일부 상쇄
  • FCF: FY26 조정 FCF 마진은 가이던스 37.5% 부합~소폭 상회, FY27 high-30s 전망으로 FY28 40% 목표 경로 유지

4FY27 가이던스 — 성장률만큼 '성장의 원천'이 중요

  • 경영진의 FY27 매출 성장 가이던스는 ~23~24%로 컨센서스(~21%)를 상회할 전망 — 통상 초기 연간 가이던스가 컨센서스 대비 ~1% 상회했던 이력 대비 이번엔 평균 이상의 상회 기대
  • FY27 부수 전망: low-20s NGS ARR 성장, high-teens RPO 성장, high-30s 조정 FCF 마진, 부담스럽지 않은 FQ1 가이던스
  • FY27 성장에는 CyberArk·Chronosphere 온기(fuller-year) 반영 효과 포함 — FQ3 기준 두 인수가 매출 ~$388M, NGS ARR ~$1.6B, RPO ~$1.8B 기여, organic NGS ARR·RPO는 각각 +28% / +22%
  • IR 커뮤니케이션 기준 Network Security가 사업의 ~70%를 차지하며 두 자릿수 성장 지속 — 클라우드 보안은 재가속보다 안정화, agentic identity는 CY27부터 유의미한 기여 전망
  • Prisma SASE·소프트웨어 방화벽·구독 attach가 하드웨어 역기저를 상쇄하며 Network Security 두 자릿수 성장 유지 — Cortex XSIAM이 Network Security 외 organic 가속의 가장 명확한 증거가 될 것
  • FY27부터 Network Security·Cortex·Identity 세그먼트별 매출 공시 신설 — organic NGS ARR/RPO, 계약 duration, FQ1 가이던스, FY27 FCF 마진과 함께 '플랫폼 가속 vs. M&A 온기'를 가려낼 핵심 체크포인트
Bottom Line플랫폼화 트렌드·방화벽 수요·XSIAM/SASE 트랙션으로 FQ4 셋업은 우호적이나, 최근 3개월 주가 +41%, CY27 EV/FCF ~57x(보안 피어 ~25x) 수준에서는 분기 실적 상회만으로는 부족. FY27 가이던스(~23~24%)와 신규 세그먼트 공시를 통한 organic 성장 가시성 확보가 관건.

1투자 논지 — 플랫폼화 전략의 수혜가 집중되는 국면

  • Mythos 이후 환경에서 보안 태세 강화를 향한 CIO의 긴박감이 가속 — 위협의 볼륨·정교함 증가와 함께 커버리지 전반에서 파이프라인 가속 확인
  • PANW는 보안 소프트웨어 시장의 주요 세그먼트 전반에 플랫폼을 구축한 최초의 전업 보안 벤더로, 신흥 AI 보안 카테고리 진입 속도도 빠름
  • 높아진 파이프라인 트랙션이 아직 가이던스에 온전히 반영되지 않아 4Q26 실적 및 FY27 전망에 업사이드 여지
  • 이번 분기 파트너·업계 대화는 매우 긍정적 — 방화벽·SASE 시장 내 점유율 통합 지속, XSIAM 견조, Prisma AIRS 초기 트랙션, CyberArk 모멘텀 확인
  • 파이프라인 창출이 유의미하게 커지면 판매 사이클 압축 가능성 — 다만 회사 측은 통상적 사이클 대비 유의미한 변화는 아직 없다는 입장
  • 어닝콜의 핵심 관전 포인트는 성장의 지속가능성과 향후 성장에서 M&A의 역할 — FY30 NGS ARR $20bn 목표는 FY26 추정치($8.94bn) 대비 ~22% CAGR(low-20s%) 함의

2NGS ARR 성장 동력 — SASE·AI 보안·플랫폼화

  • 4Q26에도 organic NGS ARR 강세 지속 전망 — SASE 모멘텀, AI 보안 채택, 광범위한 플랫폼화가 견인
  • SASE가 NGS ARR 성장의 앵커: 3Q26 SASE displacement 약 50건, 소프트웨어 방화벽·클라우드 전송 보안 채택 지속
  • Prisma AIRS: 3Q26 고객 수 3배 증가, 향후 몇 분기 내 ARR $100mm 가시성 제시
  • Portkey 인수로 AI gateway 기회 공략 — 월간 수조 개 토큰 처리, 대규모 agent 간 상호작용의 enforcement point 역할로 에이전트 확산 시 추가 수익화 레버
  • FY26 인수 관련(inorganic) NGS ARR 가정을 딜 종결 시점 $50mm에서 $150mm로 상향 — 대형 frontier AI lab이 기존 업체에서 이관하며 Chronosphere 소비를 계획보다 빠르게 확대한 영향, AI-native 트랙션의 방증
  • CyberArk는 인수 후 첫 분기부터 성장·수익성 모두 계획 상회 — 통합 진전·크로스 플랫폼 딜 확대에 따른 추가 업사이드 여지, Venafi 인증서 솔루션은 차세대 trust security 상위 구독에 편입되어 AI 인프라·머신 아이덴티티 확산과 함께 모멘텀 기대
  • 고급 virtual patching 오퍼링 신설 — 초기 매출은 professional services를 통해 인식
참고 · NGS ARR 정의NGS ARR은 Prisma·Cortex·Network Security·identity·observability를 포함한 전체 유효 계약의 연환산 매출로, 하드웨어·레거시 부속 구독·professional services는 제외. CyberArk와 달리 선불 term license 매출도 NGS ARR에서 제외되는 점이 계산 방식의 차이.

3마진 경로 — AI 지출 선행 국면에서도 복수의 레버 확보

  • 메모리 원가 상승에도 소프트웨어 중심 믹스와 운영 효율 레버로 마진 궤적 유지 전망
  • 4월 초 하드웨어 가격 10% 인상 단행 — 반복매출 구조(CyberArk 제외 사업의 84~85%)를 자연 헤지로 활용
  • 경영진은 FCF 마진을 37% 이상 수준으로 앵커링(cash tax 지원) — 시너지 목표 달성 시점을 3~6개월 앞당기고 12~18개월 내 마진 수렴 예상, FY28 FCF 마진 40% 경로 강화

4FY27 세그먼트 공시 개편 — 플랫폼 전략과 리포팅 정렬

  • FY27부터 Network Security / Cortex / Identity 세그먼트별 매출 공시로 전환
  • 구성 전망: Network Security = 방화벽·SASE·클라우드 전송 보안 서비스, Cortex = XSIAM·XDR·Cortex Cloud, Identity = 특권접근(privileged access)·ITDR
  • 크로스 플랫폼 딜의 할인 구조상 organic vs. inorganic 귀속이 자의적이어서 세그먼트 관점이 통합 사업 관리 실태를 더 잘 반영한다는 취지 — 모델링 연속성을 위해 최소 1개 기간의 y/y 비교 제공 약속
